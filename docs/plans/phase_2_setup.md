
# Giai đoạn 2: Cài đặt & Seed Database

## Mục tiêu
Khởi tạo cơ sở dữ liệu và nạp dữ liệu mẫu vào bản demo \demos/simple\ (tên package \mdash-demo\).

## Các bước thực hiện
1. Đảm bảo \pnpm install\ và \pnpm build\ đã được chạy thành công ở bước trước.
2. Chạy \pnpm --filter emdash-demo seed\ để tạo file \data.db\ và insert dữ liệu mẫu.
3. Kiểm tra file \demos/simple/data.db\ được tạo ra.
4. Lập báo cáo \docs/plans/report_phase_2.md\.
