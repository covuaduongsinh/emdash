
# Giai đoạn 1: Khảo sát Kiến trúc và Cấu trúc dự án

## Mục tiêu
- Hiểu rõ vai trò của các thư mục chính: \packages/\, \pps/\, \demos/\.
- Nắm bắt cách hoạt động của các core packages:
  - \packages/core\ (Astro integration, xử lý DB, Storage).
  - \packages/admin\ (React SPA cho giao diện quản trị).
- Tìm hiểu Plugin system (cách đăng ký, capabilities, chạy sandbox).

## Các bước thực hiện
1. Liệt kê và đọc mô tả của các packages.
2. Tìm hiểu cơ chế database qua \packages/core/src/emdash-runtime.ts\ và schema registry.
3. Đọc hiểu file \mdash-demo\ để biết cách một site Astro tích hợp EmDash.
4. Tổng hợp thành file báo cáo \docs/plans/report_phase_1.md\.
