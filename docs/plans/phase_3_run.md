
# Giai đoạn 3: Khởi động & Giới thiệu chức năng

## Mục tiêu
Khởi động server ở môi trường phát triển và kiểm tra hoạt động của phần mềm trên trình duyệt.

## Các bước thực hiện
1. Chạy lệnh \pnpm --filter emdash-demo dev\.
2. Kiểm tra log khởi động để lấy port.
3. Chờ vài giây và \curl\ thử \http://localhost:<port>/_emdash/api/init-status\.
4. Viết báo cáo \docs/plans/report_phase_3.md\ mô tả các tính năng chính có thể tương tác tại \/_emdash/admin\.
